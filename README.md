# Andrade Cardoso Digital Hub

Desenvolva um site completo para o escritório de advocacia Andrade Cardoso: Conecte a todas as redes sociais, integre em tempo real com os maiores sites que tratam de jurisprudência, tenha painel administrativo com diversas funções essenciais para a organização e CRM, acompanhamento e captação de novos clientes e que seja implementada automação para resposta de e-mails, follow-up de clientes, whatsapp e outros canais.
Por fim, que seja um site profissional que irá elevar o status do escritório e aumentar a receita recorrente
No Quadro de Sócios: Coloque um em cada caixa: Maurilo Cardoso - Delegado OAB/Cametá e Lorenzo Cardoso - Engenheiro de Software e Automação
